# Phase 1 — 한국어 STT 검증 계획

## 목적

WhisperKit의 한국어 강제 지정(`ko`)이 실제 iPhone에서 안정적으로 동작하는지 확인하고 MVP 엔진과 기본 모델 크기를 결정한다.

## 완료 조건

- 한국어 발화를 영어 번역 없이 한국어로 전사한다.
- 10초 이하 발화의 녹음 종료부터 텍스트 삽입까지 p50 3초 이내를 목표로 한다.
- 연속 20회 받아쓰기에서 앱과 키보드 익스텐션 크래시가 없다.
- 네트워크를 끈 상태에서 모델이 설치된 뒤 동일하게 동작한다.
- tiny/base/small 결과를 같은 문장과 같은 기기에서 비교한다.

## 구현 범위

1. STT 명시 언어 선택지에 한국어(`ko`)를 추가한다. — 완료
2. WhisperKit 호출 직전 해석된 언어 코드가 `ko`인지 테스트한다. — 완료
3. 후처리/Polish 기능은 꺼서 순수 STT 결과를 측정한다.
4. 모델별 지연 시간, peak memory, 결과 텍스트를 기록한다.

한국어는 아직 키보드 언어가 아니다. STT 전용 `TranscriptionLanguage`에만 등록해 기존 라틴 키보드 레이아웃과 자동수정 사전에 영향을 주지 않는다.

## 로컬 검증 상태

- `TranscriptionLanguageModeTests`: 통과
- `TranscriptionLanguagePolicyTests`: 통과
- `PendingDictationTests`: 통과
- `TranscriptionHistoryStoreTests`: 통과
- 위 4개 테스트 스위트: 총 73개 테스트 통과
- Xcode 26.6 iOS Simulator 전체 빌드: 통과

FluidAudio 0.12.4의 `StreamingAsrManager.swift`에서 Swift 동시성 오류 3건이
발생했으나, 수정이 반영된 0.13.4를 정확 버전으로 고정해 해소했다. 한국어
변경 파일과 FluidAudio를 사용하는 기존 앱 코드가 함께 컴파일되며 메인 앱,
키보드 익스텐션, 위젯 익스텐션 산출물 생성을 확인했다.

한글 자판, 한국어 자동수정, 개인 사전, UI 전체 번역은 이 단계에 포함하지 않는다.

## 테스트 데이터셋

최소 30문장을 준비한다.

| 범주 | 수량 | 예시 특성 |
|---|---:|---|
| 일상 대화 | 10 | 조사, 축약, 존댓말 |
| 메신저 입력 | 5 | 짧은 구어체, 이모지 문맥 |
| 업무 문장 | 5 | 이메일/일정/숫자 |
| 고유명사 | 5 | 사람명, 회사명, 지명 |
| 혼합 언어 | 5 | iPhone, Swift, WhisperKit 등 영문 포함 |

각 문장은 조용한 환경과 생활 소음 환경에서 한 번씩 녹음한다. 모델 비교 시 같은 녹음 파일을 재사용해 입력 차이를 제거한다.

## 기록 항목

| 항목 | 설명 |
|---|---|
| 기기/OS | 예: iPhone 15 Pro, iOS 26.x |
| 모델 | tiny, base, small |
| 오디오 길이 | 초 |
| 전사 지연 | 녹음 종료부터 결과 반환까지 |
| 삽입 지연 | 녹음 종료부터 텍스트 필드 반영까지 |
| Peak memory | 앱과 키보드 익스텐션을 구분 |
| 기준 문장/결과 | 원문과 실제 전사 |
| CER | 한국어는 띄어쓰기 영향 분리를 위해 문자 오류율을 우선 사용 |
| WER | 단어 오류율을 보조 지표로 사용 |
| 실패 유형 | 누락, 반복, 번역, 환각, 문장부호, 고유명사 |

## Go/No-Go 규칙

- **Go**: base 또는 small이 실사용 문장에서 허용 가능한 CER을 보이고 목표 지연/안정성을 만족한다.
- **조건부 Go**: 정확도는 충분하지만 지연이나 메모리가 목표를 벗어난다. 기본 모델을 낮추거나 로딩/워밍 전략을 먼저 최적화한다.
- **No-Go**: small에서도 핵심 문장 오류가 반복되거나 한국어 강제 지정이 안정적으로 유지되지 않는다. SenseVoice CoreML 검증으로 전환한다.

정확도 임계값은 1차 사용자 테스트 결과를 본 뒤 확정한다. 숫자 하나로 조기 고정하면 고유명사나 메신저 문장처럼 제품상 중요한 실패를 가릴 수 있다.
