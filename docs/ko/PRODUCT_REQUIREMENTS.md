# 온디바이스 한국어 음성 키보드 — 제품 요구사항

버전: v0.1  
작성일: 2026-09-11

## 목표

Dictus의 MIT 코드베이스를 기반으로 한국어를 지원하는 독자 브랜드의 iOS 음성 키보드를 만든다. 음성 인식은 완전히 온디바이스에서 처리하며, 최초 모델 다운로드 뒤에는 오프라인으로 동작한다.

제품 원칙은 다음과 같다.

- 무료이며 구독이 없다.
- 음성과 변환 텍스트를 외부 서버로 보내지 않는다.
- 음성에서 텍스트로의 변환에 집중한다.
- MIT 원저작자 고지와 라이선스를 유지한다.

## MVP

| ID | 기능 | 완료 기준 |
|---|---|---|
| F-01 | 커스텀 키보드 등록 | iOS 설정에서 키보드를 추가할 수 있다. |
| F-02 | Full Access 안내 | 마이크 사용에 필요한 이유와 설정 방법을 한국어로 안내한다. |
| F-03 | 녹음 시작/종료 | 키보드에서 음성 녹음을 명확하게 제어할 수 있다. |
| F-04 | 한국어 온디바이스 STT | 검증된 Whisper 모델이 `ko`로 전사한다. |
| F-05 | 텍스트 삽입 | 현재 포커스된 필드에 결과가 삽입된다. |
| F-06 | 모델 다운로드 | 최초 다운로드 진행률과 오류 복구를 제공한다. |
| F-07 | 기본 키보드 전환 | 시스템의 다음 키보드로 이동할 수 있다. |
| F-08 | 한국어 UI | 메인 앱과 키보드의 사용자 문자열을 한국어로 제공한다. |

## 비기능 요구사항

- 네트워크는 모델 다운로드에만 사용한다.
- 10초 이하 발화는 녹음 종료 후 2~3초 이내 삽입을 목표로 한다.
- 키보드 익스텐션의 메모리 한도 안에서 크래시 없이 동작해야 한다.
- 모델 설치 뒤 비행기 모드에서도 전체 받아쓰기 흐름이 동작해야 한다.
- VoiceOver 라벨과 포커스 순서를 제공한다.
- 발열, 배터리, peak memory는 실기기에서 기록한다.

## 이번 버전의 비목표

- macOS 및 Android 동시 개발
- Handy 또는 Dictus 브랜드 사용
- 클라우드 문법 교정, 톤 조정, 생성형 편집
- 개인 사전, 모델 선택, 다국어 확장, SenseVoice 선택 UI

## 기술 방향

| 영역 | 선택 |
|---|---|
| 플랫폼 | Swift, SwiftUI, iOS 17+ |
| STT 1순위 | WhisperKit + Core ML |
| STT 대안 | SenseVoice CoreML |
| 오디오 | 기존 AVAudioEngine/VAD 경로 재사용 |
| 프로세스 구조 | 키보드 익스텐션 + 메인 앱 + App Group |
| 공유 로직 | 기존 DictusCore를 경계로 유지하고 Phase 2에서 패키지 경계를 재평가 |

업스트림 최신 구조에서는 WhisperKit 모델이 메인 앱 프로세스에서 동작하고 키보드가 App Group 핸드오프로 결과를 받는다. 메모리 위험을 줄이므로 Phase 1에서는 이 구조를 유지한다.

## 로드맵

1. Phase 0: 포크, 원격 저장소 정책, 원본 빌드 확인
2. Phase 1: `ko` 강제 지정과 tiny/base/small 실기기 비교
3. Phase 2: STT 엔진과 UI 경계 정리
4. Phase 3: 브랜드, Bundle ID, App Group, 아이콘, 한국어화
5. Phase 4: MVP 기능 완성
6. Phase 5: 실기기 QA와 TestFlight
7. Phase 6: 개인정보처리방침, 스토어 에셋, 심사
8. Phase 7: 피드백과 upstream 선택 반영

## 주요 의사결정 게이트

- Phase 1에서 WhisperKit 한국어 품질이 부족하면 SenseVoice 검증으로 전환한다.
- 브랜드명 확정 전에는 App Store 등록, 도메인, 상표 검색을 진행하지 않는다.
- Bundle ID와 App Group은 Apple Developer Team 및 브랜드명 확정 뒤 교체한다.
- TestFlight 시작 전 유료 Apple Developer Program 가입 여부를 확인한다.

## 라이선스와 크레딧

기존 `LICENSE` 파일을 제거하거나 원저작자 고지를 변경하지 않는다. 출시 앱과 저장소 문서에는 Dictus 기반임을 명시하는 크레딧을 제공한다. `Dictus`와 `Handy`는 제품명으로 사용하지 않는다.
